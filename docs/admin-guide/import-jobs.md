# Задачи импорта

Харвест книг из Wikidata работает в фоне. Все такие задачи видны в «Импорт → Задачи» (страница «Задачи харвеста»). Страница обновляется сама каждые 5 секунд.

## Как читать список

Таблица со столбцами «ID», «Статус», «Запуск», «Результат».

- **«Статус»** показывает состояние задачи:
  - `pending` — стоит в очереди. Задачи выполняются по одной, поэтому ручная задача ждёт, пока закончится автоматическая;
  - `active` — выполняется (в столбце «Результат» индикатор «обработано / всего» или «Выполняется…»);
  - `retry` — не получилась и ждёт повторной попытки (система повторяет задачу до 3 раз);
  - `completed` — завершена;
  - `archived` — исчерпала попытки или не уложилась во время (лимит одной задачи — 30 минут) и закончилась ошибкой.
- **«Запуск»**: метка «Вручную» — задачу запустили вы или коллега, «Авто» — запустил планировщик (для авторов с включённым «Автоматически пополнять книги из Wikidata»); под меткой — «Авторов: N».
- **«Результат»** у завершённой задачи: «создано N, пропущено M, ошибок K». Если в конце задачи обновлялись данные авторов, добавляется строка «Авторов обогащено из Wikidata: N». У упавшей задачи в столбце показан текст последней ошибки.

Список ограничен: показано до 50 задач на состояние, а результаты хранятся около суток — старые задачи пропадают.

## Поиск экранизаций для всего каталога

Кнопка «Найти экранизации для всего каталога» (вверху страницы) ставит в очередь одну фоновую задачу: она спрашивает Wikidata про экранизации всех опубликованных книг с QID, по 50 книг за раз. Связи только добавляются: скрытые вами остаются скрытыми, а фильмы, которые вы правили вручную, не меняются.

1. Нажмите кнопку и подтвердите: «Найти экранизации в Wikidata для всех опубликованных книг с QID? Задача выполнится в фоне.» → «Запустить» (или «Отмена» — ничего не произойдёт).
2. Появится одно из сообщений: «Поиск экранизаций по каталогу поставлен в очередь.», «Поиск экранизаций по каталогу уже выполняется.» (такая задача уже есть, вторая не создаётся) или «Не удалось запустить поиск экранизаций.» (попробуйте позже).
3. Пока такая задача в очереди, выполняется или ждёт повтора, кнопка недоступна.

Задача делит единственное «окно» выполнения с харвестом: пока она идёт, новый харвест ждёт в `pending`, и наоборот. Поэтому запускайте её, когда нет срочных импортов.

Как читать строку такой задачи:

- под меткой «Вручную» / «Авто» написано «Поиск экранизаций» (вместо числа авторов);
- пока задача выполняется, в «Результате» индикатор «обработано / всего» по книгам;
- у завершённой: «Книг: 683 из 683, обновлено: 40, добавлено экранизаций: 75, ошибок: 0» — «обновлено» это число книг, у которых появилась новая экранизация, «добавлено экранизаций» — число новых связей;
- если есть ошибки, появляется «Подробнее»: таблица «Название» и «Причина» («Wikidata недоступна» или «Не удалось сохранить экранизации»). Показаны первые 50 ошибок; остальные — строкой «Ещё ошибок: N». Повторный запуск безопасен.

Если Wikidata недоступна три запроса подряд, попытка прерывается и задача повторяется позже с самого начала (до 3 повторов); уже найденные связи остаются, а в повторном отчёте они считаются как «без изменений».

Автоматический еженедельный запуск существует, только если его включили в настройках развёртывания (по умолчанию он выключен); такие задачи помечены «Авто». Спросите разработчика, включён ли он у вас.

## Что делать после успешной задачи

У завершённой задачи с созданными книгами есть кнопки «К очереди на проверку» и «К авторам на модерации»: книги и авторы придут со статусом «На модерации». Проверьте и опубликуйте их по главе [Проверка каталога](./catalog-review.md).

## Что значат ошибки и пропуски

Если у задачи есть ошибки или пропущенные записи, появляется кнопка «Подробнее» (потом «Скрыть»). В развёрнутом виде:

- блок **«Ошибки»** (столбцы «№», «Название», «Причина») — записи, которые не удалось создать; остальные записи задачи это не затрагивает;
- блок **«Пропущено»** с причиной «уже есть в каталоге (совпадение по внешнему источнику)» — запись уже была импортирована раньше или отклонена; повторно она не создаётся. Это нормально.

## Что делать, если задача завершилась ошибкой

1. Прочитайте текст в столбце «Результат» и блок «Ошибки».
2. Если Wikidata временно недоступна (в тексте ошибки это видно), подождите и запустите харвест повторно в «Импорт → Книги → Wikidata». Повторный запуск безопасен: уже созданные записи пропускаются.
3. Проверьте QID автора: он должен иметь вид `Q` и цифры и соответствовать нужному человеку. Исправьте и запустите заново.
4. Если нужны всего несколько книг, добавьте их вручную: «Импорт → Книги → Вручную» ([Как добавить книгу, автора или жанр](./adding-content.md)).
5. Задача долго остаётся в `pending` или `active`, или одна и та же ошибка повторяется у нескольких задач подряд — сообщите разработчику, указав ID задачи (первые символы из столбца «ID») и текст ошибки.

## Задачи на других страницах

Недавние задачи также показаны на странице «Обзор», блок «Задачи харвеста»: счётчик «в работе: N», ссылка «Все задачи →» и кнопка «Запустить харвест».
