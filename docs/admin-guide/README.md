# Руководство пользователя админки

Руководство для администраторов и модераторов BookHaven. Оно построено по задачам («как добавить книгу», «что делать, если импорт упал»), а не по страницам.

Те же файлы показываются внутри админки в разделе «Справка» (`/help`), а значок «?» над содержимым каждой страницы открывает нужную главу. Содержимое справки фиксируется при сборке админки: исправленная глава появится после следующей сборки.

## Кто что читает

- **Модератор** — только [Модерация отзывов](./moderation.md). Остальные главы ему недоступны.
- **Администратор** — все главы; начните с [Первых шагов](./getting-started.md).

## Главы

1. [Первые шаги](./getting-started.md) — вход, роли, карта разделов, статусы записей.
2. [Как добавить книгу, автора или жанр](./adding-content.md) — четыре способа (Wikidata, ИИ, файл, вручную) и когда какой.
3. [Задачи импорта](./import-jobs.md) — как читать список задач и что делать при ошибке.
4. [Подборки и ИИ-кураторы](./collections.md) — ручные и автоматические подборки, черновики ИИ.
5. [Проверка каталога](./catalog-review.md) — очереди книг, авторов, жанров, проверка ИИ, описания ИИ.
6. [Модерация отзывов](./moderation.md) — для модератора: скрыть и восстановить отзыв.
7. [Слияние дублей](./duplicates.md) — слияние авторов и жанров.
8. [Экранизации](./screen-works.md) — экранизации книг и фильмы об авторах.
9. [Пользователи и роли](./users-roles.md) — смена ролей.

## Для разработчиков

Название главы в первой строке файла (`# ...`) должно совпадать с реестром глав в `apps/admin/src/shared/config/help.ts`; имя файла — это slug главы. Файл `README.md` в справке не показывается. Ссылки между главами пишутся в виде `./<slug>.md`. Фича, меняющая UX админки, обновляет соответствующую главу в том же PR (см. `docs/PIPELINE.md`).

Скриншоты и обучающий тур для новых модераторов планируются отдельными задачами.
