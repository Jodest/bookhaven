# Проверка каталога

Всё, что пришло из импорта Wikidata, из «Подбора ИИ» или было создано «на модерации», ждёт вашей проверки в разделе «Модерация». Пока запись не опубликована, читатели её не видят.

## Очереди книг, авторов и жанров

Вкладки «Модерация → Книги», «Авторы» и «Жанры» устроены одинаково. Число рядом с вкладкой — сколько записей ждёт проверки.

1. Вверху статусы: «На модерации», «Опубликованные», «Отклонённые». Откройте «На модерации».
2. Найдите нужную запись: поле поиска (по названию или ISBN для книг, по имени для авторов, по названию для жанров) и фильтры вкладки:
   - книги: «Источник: любой» / «Вручную» / «Харвестер» и фильтр «ИИ» (см. ниже);
   - авторы: «QID: любой» / «С QID» / «Без QID» и «Книги: любые» / «Без книг»;
   - жанры: «Все» / «С QID» / «Без QID».
3. Решите по каждой записи:
   - **«Опубликовать»** — запись становится видимой читателям;
   - **«Отклонить»** — запись скрыта и остаётся в базе, чтобы импорт не создавал её снова;
   - **«Вернуть на модерацию»** — на вкладке «Отклонённые» возвращает запись в очередь (там же есть «Опубликовать»).
   На вкладке «Опубликованные» доступно только «Отклонить».
4. Каждое действие просит подтверждения. Если вы отклоняете автора или жанр, у которого есть опубликованные книги, предупреждение объяснит последствия: имя автора остаётся на страницах книг без ссылки, а жанр с этих книг пропадает.

### Групповые действия

Отметьте строки флажками (флажок в заголовке — «Выбрать все на странице») и нажмите «Опубликовать выбранные (N)», «Отклонить выбранные (N)» или «Вернуть на модерацию (N)». Результат показывается как «Обновлено N из M.»; если часть записей не обновилась, ниже перечислены первые ошибки с названиями записей.

### Подсказки о дублях

Столбец «Возможно, та же книга» / «Возможно, тот же человек» / «Возможно, тот же жанр» показывает похожие записи и причину: у книг «тот же ISBN», «то же название и автор»; у авторов «то же имя», «фамилия и инициал», «фамилия»; у жанров «то же название», «та же основа», «общее слово». Это только подсказка, ничего не делается само. Пометка «разные QID — вероятно, тёзки» (у жанров «возможно, разные понятия») подсказывает, что это скорее разные записи. Если запись — действительно дубль, слейте её по главе [Слияние дублей](./duplicates.md).

### Проверка ИИ для книг

В столбце «ИИ» очереди книг может быть вердикт: «Опубликовать», «Отклонить» или «Нужен человек», уверенность в процентах, причины («дубликат», «не на русском», «не книга», «сборник», «периодика», «отрывок», «неверный автор», «жанр не подходит», «мало данных» и т. п.) и пометка «устарел», если данные книги изменились после проверки. Вердикт — только совет: ни одна книга не публикуется без вашего клика.

- Фильтр «ИИ: любой» / «ИИ: опубликовать» / «ИИ: отклонить» / «ИИ: нужен человек» / «ИИ: без проверки».
- Если проверка ИИ включена, на вкладке «На модерации» видны «Без проверки ИИ: N», кнопка «Проверить ИИ все непроверенные» и «Проверить ИИ (N)» для выбранных строк. Вердикты появляются через несколько минут.
- Кнопка «Выбрать уверенные «Опубликовать» (N)» отмечает на странице только книги с вердиктом «публиковать», уверенностью от 90 %, неустаревшим вердиктом и без подсказки о дубле. После неё нужно всё равно нажать «Опубликовать выбранные (N)» и подтвердить.

### Дополнительные кнопки в очередях

- Книги: «Найти экранизации в Wikidata» (и массовая «Найти экранизации в Wikidata (N)» для выбранных книг с QID) — см. [Экранизации](./screen-works.md).
- Авторы: «Обогатить из Wikidata» (дозаполняет пустые даты и фото, ничего не перезаписывает), «Найти фильмы об авторе в Wikidata» и «Слить».

## Описания ИИ

Вкладка «Модерация → Описания ИИ» нужна для книг без собственного описания: ИИ предлагает черновик, он попадает на сайт только после вашего одобрения.

1. Если функция включена, вверху видно «Книг без описания: N» и кнопку «Сгенерировать для книг без описания».
2. Фильтр статусов: «Черновики», «Одобренные», «Отклонённые», «ИИ не знает», «Ошибки».
3. В каждой строке — книга (ссылка на её страницу редактирования), текст описания, пометки «устарел» и «есть своё описание».
4. Действия: «Одобрить», «Изменить и одобрить» (откроется поле «Текст описания», сохраните «Одобрить с изменениями»), «Отклонить».
5. На сайте одобренное описание показывается с пометкой «Описание создано ИИ и может содержать неточности.» и только пока у книги нет собственного описания.

То же можно сделать на странице редактирования книги, в блоке «Описание ИИ» («Сгенерировать», «Сгенерировать заново», «Одобрить», «Отклонить»).

## Каталог: найти и исправить

Раздел «Каталог» (вкладки «Книги», «Авторы», «Жанры», «Фильмы и сериалы») — это уже существующие записи.

- Поиск и фильтры (у книг — «Все авторы», «Все жанры», «Источник»: «Добавлено вручную» / «Импортировано»; у всех — «Все статусы»).
- «Редактировать» открывает страницу «Редактирование книги / автора / жанра». Сохраните изменения кнопкой «Сохранить».
- «Снять с публикации» (только у опубликованных записей) после подтверждения возвращает запись в очередь «На модерации».
- Кнопка «Очередь модерации» ведёт в соответствующую очередь.
- У автора на странице редактирования есть флажок «Автоматически пополнять книги из Wikidata» (нужен Wikidata QID): планировщик будет периодически запускать харвест его книг; рядом видна дата последнего автоматического запуска.
