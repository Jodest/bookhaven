# Как добавить книгу, автора или жанр

Все способы добавления находятся в разделе «Импорт». Выберите вкладку нужной сущности («Книги», «Авторы», «Жанры»), а под ней — способ. В «Каталоге» кнопки «Добавить» нет: там записи ищут, редактируют и сливают.

## Какой способ выбрать

| Что добавляю | Способ | Когда использовать |
| --- | --- | --- |
| Много книг известных авторов | «Импорт → Книги → Wikidata» | Нужно подтянуть книги целого автора (или нескольких). Работает в фоне, результат приходит на модерацию. |
| Партия книг из таблицы | «Импорт → Книги → Из файла» | Есть готовый список в `.csv` или `.json` (до 500 строк). |
| Одна книга | «Импорт → Книги → Вручную» | Книги нет в Wikidata, нужно быстро завести одну запись или автозаполнить её по ISBN. |
| Один автор из Wikidata | «Импорт → Авторы → Wikidata» | Знаете имя автора; нужен его профиль и, при желании, его книги. |
| Автор вручную | «Импорт → Авторы → Вручную» | Автора нет в Wikidata или у него там нет русского названия. |
| Много авторов по теме | «Импорт → Авторы → Подбор ИИ» | Нужно расширить каталог «вслепую», например «русская классика XIX века». |
| Жанр из Wikidata | «Импорт → Жанры → Wikidata» | Знаете название литературного жанра. |
| Жанр вручную | «Импорт → Жанры → Вручную» | Жанра нет в Wikidata или нужно своё название. |

Правило выбора: **сначала пробуйте Wikidata** — так записи получают QID и в дальнейшем не дублируются; вручную заводите то, чего в Wikidata нет; файл удобен для партий; «Подбор ИИ» — только для поиска новых авторов.

## Wikidata

### Книги: харвест

1. Откройте «Импорт → Книги → Wikidata» (страница «Импорт книг: харвест Wikidata»).
2. Выберите авторов:
   - «Поиск по имени» — введите имя, нажмите «Найти» и «Добавить» рядом с нужным кандидатом (выбранные показаны в списке «Выбранные авторы», убрать — «×»);
   - или «Ввести QID вручную» — поле «QID авторов Wikidata», по одному QID на строку или через запятую, например `Q7200`.

   В одной отправке используется только один из двух режимов.
3. При необходимости задайте «Лимит (необязательно)» — это максимум произведений, которые вернёт запрос (по умолчанию 500, не больше 5000), а не число авторов.
4. Нажмите «Запустить харвест». Появится сообщение «Харвест запущен…» со ссылкой «К задачам».
5. Ход выполнения смотрите в «Импорт → Задачи» ([Задачи импорта](./import-jobs.md)). Готовые книги появятся в «Модерация → Книги» на вкладке «На модерации».

### Автор

1. «Импорт → Авторы → Wikidata»: введите имя в поле «Имя автора в Wikidata» и нажмите «Найти».
2. У каждого кандидата есть описание из Wikidata и, если автор уже в каталоге, его статус.
3. Кнопки:
   - «Импортировать автора» — создать автора (он ждёт модерации);
   - «Импортировать с книгами» — создать автора и сразу запустить харвест его книг (нужно подтвердить вопрос; книги придут скрытыми, в очередь проверки);
   - «Импортировать книги» — если автор уже в каталоге, запустить харвест его книг.

   У ранее отклонённого автора вместо кнопок написано «Отклонён ранее»: заново он не создаётся.
4. Если совпадений нет, страница предлагает создать автора в разделе «Вручную».

Возможные отказы: «У элемента Wikidata нет русского названия — импорт невозможен» (создайте автора вручную), «Элемент Wikidata не является человеком или псевдонимом — импорт отменён.», «Wikidata недоступна, попробуйте позже.».

### Жанр

1. «Импорт → Жанры → Wikidata»: введите название в поле «Название жанра в Wikidata», нажмите «Найти».
2. Нажмите «Импортировать» у подходящего кандидата. Жанр попадает в «Модерация → Жанры».
3. Вместо кнопки могут стоять пометки «Уже в каталоге», «Отклонён ранее» или «Нет русского названия».

## ИИ: «Подбор ИИ» (только авторы)

1. Откройте «Импорт → Авторы → Подбор ИИ». Если на странице написано «Подбор ИИ выключен», функция не включена на сервере: используйте другие способы или обратитесь к ответственному за сервер.
2. В поле «Каких авторов не хватает в каталоге?» опишите запрос, например «русская классика XIX века». В поле «Сколько авторов» укажите, сколько имён предложить, и нажмите «Подобрать авторов». Есть дневной лимит («Сегодня: N из M»); пока ваш запрос выполняется, новый создать нельзя.
3. ИИ предлагает только имена, каждое сверяется с Wikidata. Статус запроса: «В очереди», «Выполняется», «Готово» или «Ошибка»; у каждого имени своя метка — «Найден», «Неоднозначно», «Не найден», «Ошибка Wikidata» или «Проверяется…».
4. Откройте запрос из списка «Недавние подборки», отметьте нужных авторов («Выбрать все найденные» / «Снять выбор»), при желании включите «Включить автопополнение книг» и нажмите «Импортировать выбранных» или «Импортировать выбранных с книгами».
5. Ничего не импортируется без вашего выбора; импортированные авторы ждут модерации.

Метка «Найден» значит лишь, что в Wikidata есть человек с таким именем — не обязательно тот, кого имела в виду модель. Проверяйте результат при модерации.

## Из файла (только книги)

1. Откройте «Импорт → Книги → Из файла». Выберите файл `.csv` или `.json` в поле «Файл (.csv или .json)».
2. В поле «Статус партии» выберите «Опубликованы» или «На модерации» — выбор относится ко всем книгам файла.
3. Нажмите «Импортировать».

Формат: у CSV обязательна строка заголовков. Колонки: `title` (обязательна), `authors` (имена через `;`), `genres` (необязательно, через `;`), а также необязательные `isbn`, `description`, `cover_url`, `published_year`, `page_count`, `language`, `slug`. JSON — массив объектов с теми же полями.

Ограничения: файл до 2 МБ и не больше 500 строк данных; для больших загрузок обратитесь к разработчику.

Результат: «Обработано», «Создано», «Пропущено (уже существуют)», «Ошибок» и таблица ошибок со столбцами «Строка», «Название», «Ошибка». Ошибка в одной строке не мешает остальным. Книга с уже существующим slug пропускается и не меняется. Недостающие авторы создаются опубликованными, недостающие жанры — на модерации (на сайте они не видны, пока вы их не опубликуете); все они перечислены в блоках «Созданные авторы» и «Созданные жанры».

## Вручную

Откройте «Импорт → <сущность> → Вручную», заполните форму и нажмите «Создать». После создания вы остаётесь на странице: форма очищается, а сообщение («Книга «…» создана», «Автор создан», «Жанр создан») содержит ссылку «Открыть» или «Открыть в каталоге» на созданную запись.

- **Книга**: «Название *» (на русском; если официальное название пишется латиницей, отметьте «Название на латинице допустимо»), «Slug» (по умолчанию из названия), «Описание», «Язык *», «Год издания», «Количество страниц», «URL обложки», «Авторы», «Жанры», «Статус». Кнопка «Найти по ISBN/названию» подставляет данные из внешнего источника; если ничего не найдено, заполните поля вручную.
- **Автор**: «Имя *», «Slug», «URL фото», «Дата рождения», «Дата смерти», «Биография». Автор создаётся опубликованным.
- **Жанр**: «Название *», «Slug», «Wikidata QID». Жанр создаётся опубликованным.

## Что дальше

Исправить запись можно в «Каталоге» кнопкой «Редактировать». Дубликаты сливаются по инструкции [Слияние дублей](./duplicates.md); импортированное проверяется по главе [Проверка каталога](./catalog-review.md).
