Запусти полный цикл разработки следующей фичи:

$ARGUMENTS

Используй feature-orchestrator.

Не реализуй фичу непосредственно в command.

Pipeline должен завершиться только одним из двух результатов:

1. PASS:
   - фича реализована;
   - Review + QA завершён со статусом PASS;
   - документация обновлена;
   - Git commit создан.

2. BLOCKED:
   - фича не прошла проверку после максимум 3 циклов;
   - Git commit не создан.
